# 小米智能存储文件快传插件

在小米智能存储 APP 与电脑客户端内生成临时下载链接和文件上传入口，当前插件版本为 `1.1.7`。

## 功能

- 为指定文件生成临时下载链接
- 为指定文件夹创建上传入口
- 可设置访问密码、有效期和最大使用次数
- 查看分享记录并一键失效
- 配置公网基础地址
- 服务启动、停止和重启
- Android、iOS 安全区和小米风格网页交互

## 多用户端口

安装器从 TCP `19092-19191` 中为每位插件用户自动分配并持久保存一个独立端口。实际端口显示在 APP 设置页的“局域网地址”中，即使服务暂时停止，该端口也不会被其他用户重复分配。

## 安装

从电脑的 WSL/Linux 运行：

```sh
cd quickshare-plugin
bash deploy.sh
```

也可以指定设备和用户：

```sh
bash deploy.sh 192.168.31.100 u123456789
```

在小米智能存储 root SSH 终端内运行：

```sh
cd /home/rootx/quickshare-plugin
bash deploy.sh u123456789
```

## 公网访问

在路由器中创建 TCP 端口转发：

- 内网主机：小米智能存储的局域网 IP
- 内网端口：APP 设置页显示的用户专属端口
- 公网端口：可以与内网端口相同，也可以自定义

然后将完整公网地址填写到 APP 的“外部基础地址”。建议使用支持 HTTPS 的反向代理；直接通过 HTTP 访问时，密码和文件内容不会被传输加密。

## 卸载

```sh
bash uninstall.sh
```

也可以指定设备与用户：

```sh
bash uninstall.sh 192.168.31.100 u123456789
```

设备本机运行时：

```sh
bash uninstall.sh u123456789
```

卸载只移除所选用户的插件、分享服务和开机任务。已经上传到用户目录的文件不会被删除。
