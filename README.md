# 小米智能存储「文件快传」插件

面向小米智能存储手机 APP 的临时文件分享插件。APP 内选择设备文件或文件夹后，可以生成临时下载链接或上传入口。

## 功能

- 单文件临时下载链接
- 可选访问密码，密码使用 PBKDF2-SHA256 哈希保存
- 1 小时至 7 天快捷有效期（后端最大允许 30 天）
- 下载或上传次数限制，达到限制自动失效
- 指定文件夹的访客上传入口，单文件最大 20 GB
- 分享记录、使用次数、最近访问时间和一键失效
- 自定义公网 IP、端口或 HTTPS 域名作为分享地址
- Android / iOS 安全区、沉浸式状态栏和左右滑动切页

## 安装

```sh
cd quickshare-plugin
bash deploy.sh
```

安装器会提示设备 IP，并扫描插件用户。也可以直接指定：

```sh
bash deploy.sh 192.168.31.100 u123456789
```

复制整个目录到设备后，也可在 root SSH 终端运行：

```sh
bash deploy.sh u123456789
```

## 端口转发

分享服务在设备上监听 TCP `19092`。路由器中创建 TCP 端口转发：

- 内网主机：小米智能存储的局域网 IP
- 内网端口：`19092`
- 公网端口：可以使用 `19092`，也可以自定义

随后在 APP → 文件快传 → 设置中填写完整公网地址，例如：

```text
http://公网IP:19092
https://share.example.com
```

插件不会自动修改路由器、防火墙或 DDNS。

## 公网安全

- 分享令牌由 192 位安全随机数生成，不能使用文件名猜测。
- 只允许分享当前用户的 `data`、`video`、`myshare`、`share2me` 和 `bak` 目录。
- 隐藏文件、符号链接、插件目录、保险箱和系统目录不会出现在文件选择器中。
- 公共页面不会列出目录；上传文件只能写入创建链接时指定的文件夹。
- 密码连续失败 5 次后，同一来源地址会被限制 10 分钟。
- 上传先写入隐藏临时文件，完整接收后再原子移动到目标文件名。
- 同名上传不会覆盖原文件，会自动添加序号。

直接使用 HTTP 暴露公网时，访问密码和文件内容不会经过传输加密。建议由支持 HTTPS 的路由器或反向代理终止 TLS，再转发到设备 `19092`。若暂时只能使用 HTTP，应依赖高强度随机链接，并避免分享敏感文件。

## 卸载

```sh
bash uninstall.sh
```

卸载会立即停止服务、撤销全部链接并删除分享记录，但不会删除已经上传到用户目录的文件。
